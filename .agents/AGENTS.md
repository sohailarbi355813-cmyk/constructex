# Proactive UI/UX Skills Rule

Before planning or making any changes to the UI/UX architecture or implementation, you MUST automatically initialize and utilize all available UI/UX skills (e.g., `impeccable`, `21st-dev`, `ui-ux-pro-max`, `ai-native-review`, `design-system`). 

**Directives:**
- Do not wait for the user to ask you to use these skills. 
- You must prioritize visual captivation, structural visual hierarchy, and professional aesthetics.
- Apply Impeccable principles and explore premium components (via 21st-dev) as a foundational step of your design process.
- Ensure that this analysis forms the basis of your implementation plan.
